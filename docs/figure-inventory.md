# 可绘图型清单（吸收阶段）

**这一页的目的**：给定数据，能画出多少种图。宽度优先，不按文献频次筛选——频次是吸收完之后做分类和排序时才用的东西，现在用它当筛子只会砍掉可选性。

条目的组织依据是**输入数据形状**，因为那决定列编码契约，也就决定 `recommend()` 能不能自动提出它。同一数据形状下的条目彼此竞争，推荐时的等级差异就体现在这里。

标记：`●` 已实现 · `○` 待实现 · `◐` 已实现但表达受限，需要扩展

**当前进度**：100 个条目中 39 个已实现、4 个已实现但表达受限、57 个待实现。

清单来源：`research/enumerate_plot_vocabulary.py` 从本地文献库 239 篇、1625 条图注中枚举出 52 种"图的形式"说法，再叠加光学领域常见表达。文献词汇只用于**发现候选**，不用于给候选排序。

## A 一维扫描：`(x, y1…yn)`

单自变量、多个响应列。光谱、功率依赖、温度依赖都落在这里。

| | 图型 | 说明 |
|---|---|---|
| ● | 多曲线折线 | 保留采集顺序与缺失间断，不自动平滑 |
| ● | 两列差值 A − B | 同一网格同类量逐点相减，带零参考线；顺序决定符号 |
| ● | 两列比值 A / B | 分母接近零的行屏蔽并在图上说明，不插值对齐 |
| ● | 多列极差包络 | 填充 min–max 加中位数；标注是极差不是标准差 |
| ● | 波长轴 + 光子能量副轴 | E = 1239.84/λ 的共轭副轴，同一数据换单位不重采样 |
| ○ | 曲线 + 填充包络 | 批次数据的 min/max 或分位数带，比画 20 条线清楚 |
| ○ | 差分谱 A−B | 带零参考线；两谱必须同一横轴网格 |
| ○ | 比值谱 A/B | 分母近零要屏蔽并标注，不能画成尖峰 |
| ● | 导数谱 d/dλ | 定位拐点与肩峰；`np.gradient` 要求横轴严格单调，重复坐标直接拒绝而不是补值 |
| ◐ | 半对数 + 指数拟合 | 现在只有线性 OLS；见 J 组模型库 |
| ○ | 对数-对数 + 幂律拟合 | 斜率即幂指数 |
| ● | 峰位与 FWHM 随参数演化 | 双曲线：λ_peak(T) 与 FWHM(T)；峰在扫描边界的角度跳过并计数，不把端点当共振 |
| ◐ | 阶梯线 | 已实现为 `spectrum_lines` 的 `step` 开关（steps-mid），不是独立图型；配了画法条目 |
| ● | 双 Y 轴 | 透射+反射、I 与 V 同图；两轴标签与刻度各自染成对应系列色，量纲必须不同 |
| ◐ | **双 X 轴** | 波长 nm ↔ 光子能量 eV 已实现；频率 ↔ 波数 cm⁻¹ 还没，二者反演关系不同不能共用变换 |
| ● | 断轴 | 只在横轴存在远宽于采样间隔的真实空洞时推荐；断口标记与省略区间为必需项，两面板共用纵轴刻度 |
| ○ | 累积/积分谱 | 累计效率、累计能量 |
| ● | 曲线与峰位标注 | 标出峰波长、峰值与半高宽跨度；峰位是三点抛物线插值，扫描边界上的极值不标注 |
| ● | 散点关系图 | |
| ○ | 事件标记时序 | 激光脉冲序列、开关时刻 |

## A′ 参数分辨扫描：`(param, x, y)`

仪器导出的第二扫描轴是**数值列**（角度、温度、延迟、门压），既不是分类标签也常常凑不成完整网格。这是光谱仪最常见的一种形状，而它和 A 组的区别只在于多了一列"第几条"。

| | 图型 | 说明 |
|---|---|---|
| ● | 曲线族（按数值参数分组） | 分组列须与横轴配对唯一——这一条把"15 个角度各一条谱"与"同一点测 15 次"分开，后者该用误差棒 |
| ● | 堆叠曲线族（二维瀑布） | 逐条上移，偏移取所有曲线的共享量程；基线是排版不是零点 |
| ● | 峰位与 FWHM 随参数演化 | 见 A 组同一行；这里是它的输入形状 |
| ○ | 三维瀑布 / 曲面 | 需要 3D 视角与遮挡处理，二维堆叠能表达同一信息且更适合印刷 |
| ○ | 差分序列（逐条减首条） | 泵浦-探测常见，属于 A 组差值在 param 方向的推广 |
| ○ | 分位数带随参数 | 批次或重复测量按参数分箱后的中位数与四分位带 |
| ● | 热图（参数 × 波长，允许缺测） | 覆盖率 60–99% 的规则扫描按 medium 推荐，缺测格留白；等值线在这种网格上不推荐，它会跨缺测区插值 |

## B 二维完整网格：`(x, y, z)`

坐标唯一且覆盖完整才成立；重复坐标不静默平均。

| | 图型 | 说明 |
|---|---|---|
| ● | 热图 | |
| ● | 填色等高线 | 会在采样点间插值，故等级低于热图 |
| ● | 等高线 + 数值标注 | `contour_labels` 开关，热图叠等高线时同样可用 |
| ● | 热图 + 叠加等高线 | 颜色保留实测格点值，等值线只标等值面经过位置；线色按色带极性自动选 |
| ● | 掩膜热图 | `missing_fill`（未测）与 `mask_below` + `masked_fill`（测了但被阈值挡掉）是两种颜色，屏蔽数量写在色标上 |
| ● | 零中心发散热图 | 有符号量自动启用 |
| ● | 行列归一化热图 | 按固定哪个坐标命名（per_y / per_x），色标必须写明口径；跨行同色不代表同值 |
| ● | 热图 + 边缘投影 | 上、右两条（沿另一轴的均值）。上下两条是同一条曲线的重复，故只做两条 |
| ○ | 三分面 x-z / y-z / x-y | 二维扫描的完整表达 |
| ○ | 3D 表面图 | 需要视角参数 |
| ○ | 3D 表面 + 底部等高线投影 | |
| ○ | 等值面 / 切片 | |

| | 图型 | 说明 |
|---|---|---|
| ● | 散点 | |
| ● | 六边形分箱 | 仅用于无序云；完整网格上无意义，已加判据 |

| | 图型 | 说明 |
|---|---|---|

## E 角度与偏振：`(theta, r)` 或偏振参量组

| | 图型 | 说明 |
|---|---|---|
| ● | 极坐标响应 | 半径非负才成立 |
| ● | dB 刻度方向图 | 径向深度随数据走、由 db_floor 封顶；0 dB 参考、对数因子与丢弃点数都写在图上 |
| ● | 多圈极坐标 | 跨度超过一圈时自动改推「极坐标 + 直角双显示」，因为不同圈落在同一条射线上 |
| ● | 极坐标 + 直角双显示 | 极坐标看对称性，直角看圈间漂移与峰背比 |
| ● | Malus 拟合 cos²θ | 见 J 组拟合库；阶数由多初值搜索确定，不靠猜 |
| ● | Poincaré 球 + 轨迹 | 以 S0 归一，点不投影到球面（半径就是偏振度）；球外点计数上报而不修正；视角是参数 |
| ○ | Stokes 四量随角度 | S0…S3 |
| ○ | DOP / DOLP / DOCP 三联 | 语料中反复出现 |
| ● | Mueller 矩阵 4×4 | 需列名 m00…m33 才认定；色标以零为中心对称，负元素才有符号含义；与转置的偏差只报数字不下互易性结论 |
| ○ | Jones 矩阵幅相双显 | 复数输入还没定义列约定，先不猜 |

## 怎么用这份清单

条数不是目标本身，**"同一份数据能拿到多少个都说得通的选项"才是**。所以判断标准是：给定一个数据形状，`recommend()` 能提出多少条、其中多少条彼此是真实替代关系（而不是 20 条都在说同一件事）。

实现顺序按**数据形状簇**推进，不按单条推进——一次做完 B 组 12 条，比在 A 组和 B 组之间来回跳要省，因为同簇共用列契约、失效边界测试和色标逻辑。

建议的推进批次：

1. **A 组补齐**（双 X 轴、差分谱、比值谱、包络、峰位演化）—— 与现有 `spectrum_lines` 同契约，边际成本最低，直接放大光谱数据的可选数
2. **B 组补齐**（掩膜、边缘投影、行列归一化、三分面、3D 表面）
3. **J 组的模型拟合** —— 它同时解锁 A、C、E 三组的多个条目
4. **E 组偏振全套** —— 你的领域核心，且当前只有 1 条
5. **C/D/H 组统计表达**
6. **I 组结构示意** —— 独立一条输入轴，工作量大但缺口也最大
